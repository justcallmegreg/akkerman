# Backend

This directory contains the backend application for the Akkerman project, including the web crawler/scraper infrastructure.

## Getting Started

See the root [README.md](../README.md) for general project information.

## Structure

- `Dockerfile` — Container configuration for the backend service
- `requirements.txt` — Python runtime dependencies
- `requirements-dev.txt` — Python development dependencies
- `akkerman/` — Scrapy crawler implementation
- `tests/` — Test suite
